# 3BB Demo Lite

Live Web SDK chat on the **3BB Demo Lite** project (agents-al.cdc.ais.th), with the Ari mascot,
a live account view and a conversation-intelligence timeline. Demo tooling only; all data is sample data.

Run locally: copy `.env.example` to `.env`, set `SDK_PUBLIC_KEY`, then `npm start` → http://localhost:5199.
On Render the four settings (`ENDPOINT`, `PROJECT_ID`, `SDK_PUBLIC_KEY`, `CHANNEL_ID`) are service environment variables.
The public key's allowed origins must include the page's origin.
